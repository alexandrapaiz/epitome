# Learning-loop ledger

The daily tick of this seat's half of the company learning loop (owner
directive, 2026-10-17, carried to this seat as a handoff on the board;
the clock is `asc-brief.timer` on the host, 12:01 UTC). One entry per
tick, in a fixed shape: what the numbers were, which attribute of the
growth model they make weakest, the week's experiment, what was acted
on, and the measurement of the previous experiment.

**This file has a ceiling, because the frameworks register's law binds
this seat first.** 120 lines. When it is exceeded, every entry older
than fourteen days collapses to its one-line verdict and the detail goes
with the run that wrote it. If a week passes and no decision anywhere
cites a line of this file, the file is cut and the cut is logged as a
lesson against this seat.
