# Frameworks register

One law: a framework must never consume more than the work it organizes.
Entry requires naming the problem it solves; one trial at a time; every
adopted practice carries a measured ceremony cost and a kill-by-default
review date. Inherited baseline from the playbook: OKRs
(Committed/Aspirational), Working Backwards (press release first — done),
the pre-mortem before launch, WIP limits, Team Topologies vocabulary.

| Framework | Problem it solves | Status | Ceremony cost | Review |
|---|---|---|---|---|
| Shape Up (ADR-5 terms) | Whether fixed-appetite betting beats sprint ceremony for a one-owner agent org; owner wants a felt comparison vs. alexandria's Scrum | **trial** | measured per PM run in the cooldown scorecard | end of cycle 2 — killed by default if unjudged |
| Minimal Scrum | (playbook default) displaced by the Shape Up trial on this project | not adopted here | — | revisit at the cycle-2 review |
