## The bet

**mvp-stranger-npm-v0** (docs/pitches/mvp-stranger-npm-v0.md) — small
batch, 3 engineer runs. A stranger runs `init`, `validate`, `deploy` and
`run` from one manifest and gets a working agent, CLI installed from
npm, the README the only guide. Every mechanism already exists on
`main`; the gap is that nobody outside this repository can reach any of
it yet.

Per the charter's scope rule, decomposed into four integrated slices,
matching the pitch's own breadboard numbering:

- **2a. Publish the package.** Tasks: the npm publish token exists
  (owner-only, done — Infisical and this repository's Actions secrets,
  landed via the chair's handoff recorded in `docs/backlog.md`); the
  publish rehearsal (`npm publish --dry-run`) actually asserts something
  about what would ship, instead of exiting clean having checked
  nothing; the real publish runs.
  Hill: `solution known, building ▼ | the dry-run rehearsal was found
  broken — it exited 0 having asserted nothing about the package a
  stranger would get — and fixed on an unmerged branch (the open
  publish-readiness chain, #130→#131→#135→#136). The real publish has
  not been run against the registry. The token is seven days old,
  issued around 2026-10-17 and dead 2026-10-24; what stands between this
  scope and done is a merge decision, not more engineering.`

- **2b. One real deploy, end to end.** Tasks: the owner or chair runs
  the deploy command for one of HQ's own seats against a real GitHub
  account, approves the one browser step GitHub requires to create the
  App, confirms the token-minting step works from it.
  Hill: `problem-side ▲ | not started. Asked on the board 2026-10-16
  18:28 UTC; no reply as of this run, two days later. This is the one

- **2c. The README verified as the only guide.** Tasks: a suite reads
  the README out of the packaged tarball (not the checkout) and drives

  Hill: `solution known, building ▼ | built and green on the same

- **2d. A regression gate for the claim itself.** Tasks: one check that

## Standing risks

1. **The publish token is a clock, not a formality.** It was issued
   roughly a week before this file opened and is dead 2026-10-24. Scopes
   2a, 2c and 2d are all built and waiting on the same merge; if the
   merge-then-publish decision has not landed by then, a new token is a
   second owner-only ask, not a cut this seat can make on its own.
2. **Scope 2b has had zero movement since it was asked.** If that
   continues to the cycle's close, the honest claim may have to ship as
   "mechanically complete, proven only in dry runs," not "proven end to
   end" — naming that possibility now, not as a surprise in the retro.
3. **This seat cannot land any of the four scopes itself.** Every hill
   line above describes work that exists and is verified, not work this
   charter can merge. The circuit breaker still applies: if the chain
   is still unmerged at cycle's end, that is unfinished work going back
   to raw material, re-bet or dropped, not rolled over silently — but
   note the cause would be a merge decision outstanding outside this
   charter, not scope that ran long.
