**1. `epito deploy` v0 — identity slice** (docs/pitches/deploy-identity-v0.md)
— big batch, the full cycle. Bet because the credentialed-principal leg
is the one thing nobody in the market brief has and every demand quote
hand-builds; it is the wedge itself, and every other card queues behind
it. Cutting order if it runs long: audit-log polish first, scope-map
breadth second, never the core mint.

Scopes (integrated slices, each independently demoable):

- **1a. Route spike + ADR** — the central unknown. Tasks: spike
  GitHub's app-manifest flow end-to-end by hand; enumerate callback
  constraints (one-shot localhost listener) and App naming/avatar
  limits; write the route ADR (app-manifest flow vs shared-App
  installations) into decisions.md for owner objection.
  Hill: `problem-side ▲ | nothing spiked; every other scope queues here`
- **1b. Principal provisioning** — `epito deploy` mints the App.
  Tasks: pre-fill the creation page from [identity].scopes; catch the
  callback; persist app id + private key to `.epito/` (0600); make
  `epito init` scaffold `.epito/` into .gitignore.
  Hill: `problem-side ▲ | blocked on 1a's route`
- **1c. Per-run token minting** — Tasks: JWT from the App key;
  exchange for a short-lived installation token; internal call plus a
  `token` subcommand; tokens never written to disk.
  Hill: `problem-side ▲ | mechanical once 1b lands (documented exchange)`
- **1d. Scope mapping** — Tasks: map `github:contents`,
  `github:pull_requests`, `github:issues` to fine-grained App
  permissions; unmapped scope fails deploy loudly; keep `epito
  validate`'s scope grammar in sync.
  Hill: `problem-side ▲ | small and well-bounded`
- **1e. Audit log** — Tasks: append-only `.epito/audit.jsonl`, one
  line per mint (agent, scopes, timestamp); optional `epito audit`
  read-back. Hill: `problem-side ▲ | first named cut if the cycle runs long`
- **1f. Idempotent redeploy + CLI polish** — the acceptance slice.
  Tasks: deploy twice updates the same principal (spec rule 4);
  vibecoder-grade error strings; help text and README deploy section
  un-WIP'd. Hill: `problem-side ▲ | closes last, by design`
