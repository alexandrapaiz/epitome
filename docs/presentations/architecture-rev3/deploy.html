6 · Flow: epito deploy

The deploy flow: manifest in, principal out.

1

core.validate(agent.toml) — refuse anything spec v0.1 refuses

2

identity.mint — one-shot localhost listener up; POST pre-filled app manifest to GitHub; human clicks Create; redirect returns a code; POST /app-manifests/{code}/conversions → App id + private key → .epito/

3

Install on the target repo; capture installationId into principals.json

4

trigger.wire + runtime.materialize — emit agent-<name>.yml: cron from [trigger], job opens with epito token

5

Audit line appended. Re-deploy = update the same principal (idempotent on name), never a duplicate
