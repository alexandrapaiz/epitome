5 · Data model

Four records, three trust levels on disk.

Manifest   = agent.toml, parsed  // publishable, never secret

Principal  = { agent, provider, externalId,

    installations[{repo, installationId}] }  // NEVER secrets

Credential = { token, expiresAt, scopes }  // in-memory ONLY

AuditEntry = { ts, agent, action, scopes, provider }  // append-only

.epito/principals.json

Safe to read aloud — records, no secrets

.epito/keys/<agent>.pem

Secret — 0600, gitignored, one per principal

.epito/audit.jsonl

Append-only — the trail that answers "which agent did that"

The split is the marketplace's precondition: a manifest publishable without redaction, state readable, secrets isolated. Tokens never persist anywhere.
