The whole system in one page.

epito turns a manifest file into a working agent. An agent is three things at once, and each thing is a pluggable provider seam. That sentence is the entire architecture; everything after this slide is detail.

If you internalize one slide, make it the provider-interfaces section (§4). Every future decision either fits those three signatures or changes them by ADR.

The design test for every decision: does core still work with zero integrations installed, and does the manifest stay publishable? A no to either is a constraint violation, not a tradeoff.
