7 · Flow: every run

The per-run token flow.

sign

Load keys/<agent>.pem; sign a 10-minute JWT, iss = App id.

exchange

POST /app/installations/{id}/access_tokens with exactly the manifest's permissions → ~1-hour installation token.

hand off

Token reaches the agent process via env, never disk. Work attributes to <name>[bot]. Audit line appended.

Scopes are the ceiling — the runtime can never acquire a permission the manifest doesn't declare; widening = a manifest diff = intent in the audit trail.

Revoke = uninstall the App — GitHub refuses every future mint; local keys deleted; nothing personal touched.
