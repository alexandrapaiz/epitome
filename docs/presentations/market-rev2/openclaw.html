People want live-in agents so badly they run dangerous ones.

OpenClaw, an open-source agent that lives on your computer, passed 135,000 GitHub stars within weeks of launch (2026). Then: 42,000 copies found exposed on the public internet, passwords stored in plain text, and roughly 1 in 8 add-ons in its store confirmed malicious.

The reading for the room: the demand for a resident agent is proven at internet scale, and so is the failure of the do-it-yourself version. Our phase 2 is exactly the three fixes OpenClaw lacked: each agent walled off in its own container, secrets out of plain text, and an identity that is not the owner's. Honest caveats we say if asked, not on the slide: we do not solve prompt injection, a bad add-on the user installs anyway, or an unpatched computer.
