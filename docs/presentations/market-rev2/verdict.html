2 · The verdict: Slack is integration #2 — owner accepted (ADR-7)

Slack passes all four laws; nothing else does.

self-serve mint, today

App created programmatically via apps.manifest.create, installed per workspace by standard OAuth — structurally the same manifest-mint flow the GitHub provider already implements. The provider is a variation on shipped code.

a first-class someone

Its own bot user, granular scopes (chat:write, assistant:write), its own name and avatar on every message, revoked by uninstall. Settles manifest v0.2's scope grammar: slack:chat.write.

the visibility surface

GitHub proves the agent works; Slack is where a human watches it work. A cron-woken agent posting its own standup under its own face is the product demo, in-situ, daily.

Honest tension: Slack is Salesforce property, and Slackbot is positioned as the orchestrator fronting third-party agents. We build our best demo surface in a competitor family's living room. Mitigation is law 1: one surface of many; the provider dies gracefully if the walls close.

Runners-up: Vercel (biggest storefront, but the bar gates the value) and Notion (real identity, 1M+ agents built, but Notion bundles residency itself).

Owner additions, same verdict: WhatsApp group chats and WeChat enter the research queue as international surfaces, evaluated under the same four laws next revision.
