3 · What happens on every run

Short-lived tokens, real attribution, a line in the log.

JWT → token

Sign a 10-minute JWT with the App key; exchange it for an installation token that expires in ~1 hour and carries only the manifest's scopes. Tokens never touch disk.

The agent acts

Commits and PRs attribute to historian[bot] — never to the owner. "Which agent did that" finally has an answer.

Audit + revoke

Every mint appends one JSONL line. Revocation = uninstall the App: one click, and nothing personal is touched.
